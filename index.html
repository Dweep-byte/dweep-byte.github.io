Social Media Screen Time & Addiction Dashboard

Developed an interactive Power BI report analyzing screen-time patterns, platform usage, and country-wise user distribution through pictorial visualizations.

  • Power BI
  • DAX
  • Power Query

Problem

Analyze how daily screentime varies across platforms and check whether high notification volume relates to longer usage durations.

Approach

Imported and cleaned a public social media screentime survey dataset from Kaggle using Power Query. Wrote DAX measures for average daily screentime and platform shares.

Dataset: Kaggle Social Media Screentime Dataset. Finding: Users receiving over 90 daily notifications averaged over 5.4 hours of daily screen time across YouTube, TikTok, and Instagram.

Customer Churn Prediction Model

Machine learning classification model in Python predicting customer cancellations from telecom service data.

  • Python
  • scikit-learn
  • pandas
GitHub

Problem

Predict whether telecom customers will cancel their subscription based on account information and service usage records.

Approach

Preprocessed the Telco dataset (7,043 rows) with pandas by handling missing values and one-hot encoding categorical fields. Trained Logistic Regression and Random Forest models using scikit-learn.

Algorithms & Results

Best Model: Logistic Regression achieved 84.5% accuracy and 0.81 F1-score. Monthly charges and month-to-month contract terms showed highest correlation with churn.

What I Learned

Understood how to evaluate models using confusion matrices, precision, recall, and ROC-AUC rather than relying on accuracy alone.
